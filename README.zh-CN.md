# 燕云033插件国际服补丁

[English](README.md)

给《燕云十六声》/ Where Winds Meet 的「033 燕云定制版」DLSS5 插件做的非官方补丁，插件作者是 [B站 @热心网友033](https://space.bilibili.com/88101991)。033 插件请只从作者的 B 站主页获取。

## 修复什么

- **让 033 的人景／人衣景分离功能在国际服启用**。为受支持版本补上国际服（`wwm.exe`）的原生遮罩支持，让原本仅对国服（`yysls.exe`）启用的分离功能也能在国际服使用。具体可用的分离选项以对应 033 版本为准，补丁不会给旧版新增功能。
- **V6.3 游戏更新后人景分离失效**（国服、国际服都有）。插件里写死了某一版游戏主程序的哈希，游戏一更新，原生遮罩就静默失效，面板却仍显示遮罩界面。补丁让这项检查直接通过；保留原有着色器哈希匹配，不修改遮罩库。
- **V6.3.5 / V6.38 / V6.3 威力加强版 R7 及结构兼容的新版本**：作者遮罩库里没有的材质不再让整帧遮罩作废，改为按场景处理（可用 `-NoRelax` 关闭）。

内置精确支持 V6.3、V6.3.5、V6.38、V6.3 威力加强版 R7。其他版本会自动尝试按代码特征定位，不再要求手工添加新 SHA-256 和文件偏移。当前自动识别针对 V6.38 / R7 这一代码结构家族；代码结构变化或匹配不唯一时拒绝修改，不能保证任意未来版本都适配。

## 用法

1. 退出游戏，用 033 安装器装好插件。
2. 双击 `apply-patch.cmd`，按命令行窗口里的提示操作：
   - 脚本会自动找到所有装了 033 的游戏，**同一个游戏的 Win64r、Win64rh 启动目录会一起处理**；
   - 国服和国际服都装了可打补丁的 033 时，会列出编号，输入编号后回车，选择要处理的游戏；
   - 动手前会列出要处理的引擎，**输入 Y 后回车确认**，输入其他内容则取消，不改动任何文件；
   - 不需要或无法打补丁的版本（例如 V6.0）会显示为“跳过”；
   - 只有游戏目录里是 `wwm.exe` 时才打国际服适配，国服只打遮罩层修复。
3. 卸载或升级 033 之前，双击 `remove-patch.cmd`，同样选择游戏并输入 Y 确认，引擎会逐字节还原到补丁前。安装新版后再次运行 `apply-patch.cmd` 即可尝试自动适配。

`check-status.cmd` 会列出找到的每个 033 引擎：国服还是国际服、033 版本、补丁状态和所在启动目录。它只查看，不写引擎，也不创建恢复副本。

补丁文件夹放在哪里都可以，只要 `apply-patch.cmd`、`check-status.cmd`、`remove-patch.cmd`、`patch-033.ps1`、`auto-detect.cs` 放在同一个文件夹里。脚本通过 033 安装器的安装记录（`%LOCALAPPDATA%\033Installer\index`）找到游戏，再根据引擎所在目录里是 `yysls.exe` 还是 `wwm.exe` 判断国服或国际服。三个 `.cmd` 会调用 `patch-033.ps1`，不用自己运行它。请保持 `auto-detect.cs` 与 `patch-033.ps1` 放在同一目录；自动定位使用 Windows PowerShell 自带的 .NET 编译器，无需另装 Python 或反汇编工具。

## 新版本自动适配

- 先核对内置版本的原版 SHA-256；未命中时读取 PE 节和 x64 函数边界，联合检查两条哈希白名单引用、游戏名检查及四处材质检查。根据实际地址重新计算国际服字符串引用，忽略会随链接变化的相对地址。
- 第一次为未知版本打补丁时，先将完整原始引擎保存到引擎旁的 `033-engine.dll.patch-033/<原始SHA-256>.original.dll`。不同原版分别保留，不覆盖旧副本。**请保留该目录**，自动适配版本的重复运行、状态识别和还原都需要它。
- 后续运行会重新校验恢复副本、从副本重新定位，并核对当前引擎只包含允许的补丁变化。补丁位置以外被改动、恢复数据损坏或缺失时停止。写入通过同目录临时文件替换完成，并在替换前再次检查游戏进程和引擎哈希。
- 自动计算的新哈希只用于识别本地原始文件和验证还原，**不能证明该文件由作者发布**。内置版本仍使用预置的原版哈希认证。只想使用内置版本时运行 `apply-patch.cmd -KnownOnly`。
- 首次自动适配需要未打过补丁的引擎；若自动识别失败，请保留报错信息，用 033 安装器恢复干净版本后重试。新版本若改变了代码结构，仍需更新定位规则，脚本不会猜测偏移或只打其中一部分。

也可手动指定引擎和客户端（指定 `-Engine` 时只处理这一个引擎，不再询问）：

```powershell
.\apply-patch.cmd -Engine 'D:\Games\WWM\033-runtime\033-engine.dll' -Client Intl
```

自动查找时如需跳过 Y 确认（例如写进自己的脚本），可加 `-Yes`。

自动适配不修改着色器库或其哈希，也不自动下载或升级 033 插件。

## 修改位置

| 版本 | 遮罩层修复 | 国际服适配 | 放宽检查 |
|---|---|---|---|
| V6.3 | `0x2F9110` | `0x29BAE0`、`0x29BAEA` | – |
| V6.3.5 | `0x327AB0` | `0x2ABB74`–`0x2ABB75` | `0x2743E5`、`0x274BE3`、`0x275423`、`0x275C51` |
| V6.38 | `0x338F40` | `0x2BA234` | `0x27CCF5`、`0x27D543`、`0x27DDD3`、`0x27E651` |
| V6.3 威力加强版 R7 | `0x33FA10` | `0x2BB824` | `0x27CD95`、`0x27D5E3`、`0x27DE73`、`0x27E6F1` |

内置版本把所有位置还原后必须与预置原版 SHA-256 完全一致；自动适配版本则使用校验过的本地原始副本。未知版本的实际偏移由扫描器产生，不使用这张表。

## 测试

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test-patch.ps1 -SampleEngine 'D:\Games\WWM\033-runtime\033-engine.dll'
```

提供内置支持且属于自动定位结构家族的真实引擎（例如 R7，已打本补丁也可）。测试只操作仓库内临时副本，结束后清理；验证固定版本回归、移动 PE 文件偏移后的自动适配、选项切换、重复运行、完整还原及拒绝异常文件。仓库不附带引擎样本。模拟文件位置移动不能替代真实未来版本的游戏内验证。
