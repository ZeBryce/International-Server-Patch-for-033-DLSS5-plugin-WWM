# 遮罩层与国际服补丁 for 033 DLSS5 插件

[English](README.md)

> 修复 033 燕云定制版 DLSS5 插件 V6.3 在游戏更新后人景分离失效的问题，并让原生遮罩在国际服上可用。

这是给 B站@热心网友033 的「033 燕云定制版」DLSS5 插件做的非官方补丁，适用于《燕云十六声》/ Where Winds Meet。

**主要针对 V6.3。** 游戏更新后，V6.3 的面板仍然显示原生皮肤遮罩的界面，但人景分离会静默失效：人物和场景得到同样的效果。国服和国际服都会遇到。本补丁修复这个问题，同时让原生遮罩在国际服（`wwm.exe`）上也能用；插件原本只对国服（`yysls.exe`）开启。

同时支持 V6.3.5 和 V6.38。

补丁只修改 033 安装器已经装到你游戏目录里的那份引擎，不包含作者的任何文件。

## ⚠️ 使用风险（请先读完）

- **这是非官方修改。** 它改的是 033 作者发布的程序，作者没有审核过，可能出现作者没测过的画面问题、闪退或其他异常。
- **网游有反作弊。** 033 本身就是注入游戏的第三方插件，使用它（以及本补丁）都可能违反游戏的用户协议。游戏方是否会因此处罚（包括封号）不在本项目控制之内，**风险由使用者自行承担**。
- **033 安装器会认为文件被改过。** 用 033 安装器「还原安装前」或升级之前，先双击 `remove-patch.cmd` 把引擎还原成原版，否则安装器可能报文件被替换、留下残留文件。
- **新版本会被拒绝。** 033 出了本补丁不认识的新版本时，脚本会直接拒绝修改；游戏更新导致着色器变化时，原生遮罩可能仍然无法覆盖全部材质。
- 作者在发布包里说明过不希望二次分发，本项目只提供补丁脚本。033 本身的问题请去找作者，补丁的问题请在本仓库提 issue，不要把补丁导致的问题反馈给作者。

## 用法

1. 完全退出游戏。
2. 用 033 安装器正常安装（或升级）033。
3. 双击 **`apply-patch.cmd`** 打补丁。脚本会从 033 安装器的记录里自动找到游戏：看到 `wwm.exe` 就同时打国际服适配，看到 `yysls.exe` 只打遮罩层修复。
4. 想卸载或升级 033 之前，双击 **`remove-patch.cmd`** 删除补丁、还原成作者原版。
5. **`check-status.cmd`** 只查看状态，不改文件。

`patch-033.ps1` 不需要自己运行，上面三个 `.cmd` 会调用它。命令行用法：

```powershell
powershell -ExecutionPolicy Bypass -File patch-033.ps1 -Action Status|Apply|Revert [-Engine <033-runtime\033-engine.dll 的路径>] [-Client Auto|CN|Intl] [-NoMaskFix] [-NoRelax]
```

## 原理

**遮罩层修复（国服、国际服都适用）**：033 的引擎里写死了作者测试时那一版国服主程序的 SHA-256（"白名单"）。插件启动时会对正在运行的游戏主程序算一遍哈希，对不上就整个跳过"着色器登记"，原生遮罩一帧都画不出来。而面板是否切换到遮罩界面看的是另一项检查，于是出现"界面是遮罩模式、画面却没有人景分离"。游戏每次更新主程序都会让白名单过期。补丁把这个检查函数开头 5 个字节改成直接返回"通过"。

着色器本身仍然按精确哈希匹配，游戏更新后对不上的着色器照样不会被替换，所以去掉主程序检查不会让遮罩套到错误的着色器上。

**国际服适配**：原生遮罩的开关只比对文件名 `yysls.exe`，补丁让它比对 `wwm.exe`。

**放宽库外材质检查（仅 V6.3.5 / V6.38）**：这两个版本只要画面里出现一个不在作者遮罩库里的材质着色器，就把整帧遮罩作废、保留原画。国际服有一部分材质不在库里，补丁让这类材质当作"场景"处理，其余照常出遮罩。代价是库外材质挡在人物前面时，那一小块可能按人物处理。可以用 `-NoRelax` 关掉。

**安全检查**：动手前，脚本先把所有补丁位置在内存里还原，结果必须与作者原版引擎的 SHA-256 完全一致才会写入。因此 `remove-patch.cmd` 不需要任何备份，还原出来的就是原版。

## 修改位置

| 版本 | 原版 SHA-256 | 遮罩层修复（5 字节） | 国际服适配 | 放宽检查 |
|---|---|---|---|---|
| V6.3 | `d69c4e8b…a42b637` | `0x2F9110` | `0x29BAE0`、`0x29BAEA` | 无 |
| V6.3.5 | `4dfe6ac3…d056b0c` | `0x327AB0` | `0x2ABB74`–`0x2ABB75` | `0x2743E5`、`0x274BE3`、`0x275423`、`0x275C51` |
| V6.38 | `721810f3…f1a329d0` | `0x338F40` | `0x2BA234` | `0x27CCF5`、`0x27D543`、`0x27DDD3`、`0x27E651` |

遮罩层修复把 `48 89 5C 24 08` 改为 `B0 01 C3 90 90`（`mov al,1; ret`）。
