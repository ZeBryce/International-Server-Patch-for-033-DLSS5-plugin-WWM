# 遮罩层与国际服补丁 for 033 DLSS5 插件

[English](README.md)

给《燕云十六声》/ Where Winds Meet 的「033 燕云定制版」DLSS5 插件做的非官方补丁，插件作者是 [B站 @热心网友033](https://space.bilibili.com/88101991)。033 插件请只从作者的 B 站主页获取。

## 修复什么

- **V6.3 游戏更新后人景分离失效**（国服、国际服都有）。插件里写死了某一版游戏主程序的哈希，游戏一更新，原生遮罩就静默失效，面板却仍显示遮罩界面。补丁让这项检查直接通过；着色器仍按精确哈希匹配，不会套错。
- **国际服（`wwm.exe`）用不上原生遮罩**。插件只对 `yysls.exe` 开启。033 的其他功能在国际服上本来就能用，不需要本补丁。
- **仅 V6.3.5 / V6.38**：作者遮罩库里没有的材质不再让整帧遮罩作废，改为按场景处理（可用 `-NoRelax` 关闭）。

支持 V6.3、V6.3.5、V6.38，其他文件一律不动。

## 用法

1. 退出游戏，用 033 安装器装好插件。
2. 双击 `apply-patch.cmd`。会自动找到游戏，只有检测到 `wwm.exe` 时才打国际服适配。
3. 卸载或升级 033 之前，双击 `remove-patch.cmd`，引擎会逐字节还原成作者原版，不需要备份。

`check-status.cmd` 只查看状态。三个 `.cmd` 会调用 `patch-033.ps1`，不用自己运行它。

## 修改位置

| 版本 | 遮罩层修复 | 国际服适配 | 放宽检查 |
|---|---|---|---|
| V6.3 | `0x2F9110` | `0x29BAE0`、`0x29BAEA` | – |
| V6.3.5 | `0x327AB0` | `0x2ABB74`–`0x2ABB75` | `0x2743E5`、`0x274BE3`、`0x275423`、`0x275C51` |
| V6.38 | `0x338F40` | `0x2BA234` | `0x27CCF5`、`0x27D543`、`0x27DDD3`、`0x27E651` |

只有把所有位置还原后与作者原版 SHA-256 完全一致，脚本才会写入。
